# Chat proposes analysis and the user confirms it

The chat-led interface converts a natural-language request into an analysis proposal containing the AOI, date windows, signals, and parameters. The user must review and confirm that structured proposal before any remote-sensing analysis runs, preserving the approachable visual workflow while making the analysis reproducible and auditable.

**Status**: accepted

**Consequences**: Ambiguous requests pause for missing information or confirmation. Every threshold override, warning, scene selection, and processing version becomes part of the analysis manifest and exported reports.
