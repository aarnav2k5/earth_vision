# Reference screens define visible product behavior

The supplied Garuda Lens reference screens are authoritative when they conflict with the written product description. This preserves the intended chat-led console, visible analysis categories, and user-facing terminology such as “Urban Expansion,” while the domain glossary continues to define the limits and meaning of those labels.

**Status**: accepted

**Consequences**: Future product and implementation decisions should reconcile the written specification to the reference screens rather than silently changing the screens to match prose. Heuristic labels shown in the screens still require visible uncertainty and limitation messaging.
